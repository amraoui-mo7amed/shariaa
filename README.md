# Shariaa

Audio recordings and PDF materials organized by subject and lesson order.

## Structure

1. `01_Three_Principles_Al-Usul_Al-Thalatha`
2. `02_Four_Principles_Al-Qawaid_Al-Arbaa`
3. `03_Conditions_of_Prayer_Shurut_Al-Salah`
4. `04_Prophets_Biography_Mukhtasar_Al-Seerah`
5. `05_Names_of_Allah_Tafseer_Al-Asmaa_Al-Husna`
6. `06_Sunnah_Creed_Aqeedat_Ahl_Al-Sunnah`
7. `07_Book_of_Tawheed_Kitab_At-Tawheed`

Each folder includes:
- `Audio/`: lesson audio files (`Lesson_01.mp3`, ...)
- `PDF/`: texts, notes, and summaries (`Lesson_01.pdf`, ...)
